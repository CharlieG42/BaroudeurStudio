## **🔧 Outils utilisés**
**Unique outil principal :**
- **`tools.image_generation.edit_image`** (via `run_typescript`)
  → **Fonction** : Transformation d’images existantes en style **Studio Ghibli** *sans création ex nihilo*.
  → **Avantage** : Permet une **édition pixel-perfect** des éléments (visages, paysages) tout en appliquant un style artistique cohérent.

---

---

## **🎨 Méthodes clés**

### **1️⃣ Style Ghibli appliqué systématiquement**
**Caractéristiques reproduites à chaque itération :**
- **Textures** : Gouache/aquarelle avec **coups de pinceau légèrement visible**, aplats légèrement irréguliers.
- **Couleurs** :
  - Verts nuancés (végétation), bleus désaturés (montagnes/ciel), ocres/bruns (rochers).
  - **Lumière** : Douce, enveloppante, légèrement dorée (évite le HDR ou les contrastes agressifs).
- **Paysages** :
  - Montagnes texturées, arbres dessinés individuellement, rochers aux formes lisibles.
  - Profondeur atmosphérique (arrière-plans progressivement simplifiés).
- **Contours** : **Doux** (formes définies par la couleur, les ombres, et des lignes fines – *pas de contours noirs épais*).
- **Personnages** :
  - Proportions naturelles, visages simplifiés (yeux petits, nez/bouche discrets).
  - Cheveux en masses peintes, vêtements simplifiés mais reconnaissables.

**À éviter** (explicitement exclus des prompts) :
❌ Photoréalisme, 3D/CGI, contours noirs nets, visages trop détaillés, grands yeux manga, couleurs fluorescentes, effet cartoon, textures uniformes superposées.

---

### **2️⃣ Gestion des visages et détails humains**
**Règles appliquées :**
- **Fidélité 100%** : Visages **non stylisés** (traits, expressions, tons de peau, positions des yeux conservés).
- **Barbes** :
  - Ajoutées *a posteriori* quand absentes (ex: `gen-image://18f7edd7` → `gen-image://e7cfe872`).
  - **Forme/longueur** : Uniformisées entre personnages (ex: barbes courtes et continues pour les 2 randonneurs).
  - **Couleur** : Alignée sur les tons de la photo originale (uniformité demandée).
- **Rajeunissement** : Ajustement des traits (peau lissée, rides atténuées) *sans altérer la ressemblance globale* (ex: personnage de droite dans `gen-image://24788f54`).

---

### **3️⃣ Processus itératif**
**Boucle de feedback utilisateur → correction ciblée :**
1. **Première passe** : Application du style Ghibli global (paysage + personnages).
   *Exemple* : `gen-image://b1842fc7` (premier selfie en Ghibli).
2. **Corrections ciblées** :
   - **Barbes** : Ajout/modification (ex: `gen-image://a5022d36` → `gen-image://18f7edd7`).
   - **Couleurs** : Réchauffement des tons (ex: `gen-image://e7cfe872` → `gen-image://809eec4d`).
   - **Visages** : Rajeunissement ou ajustement des traits (ex: `gen-image://24788f54`).
3. **Validation** : L’utilisateur valide à 95% les dernières images (ex: `gen-image://809eec4d`, `gen-image://2411ccd7`).

**Exemple concret de chaîne de corrections** :
```

```

### **4️⃣ Prompts types utilisés**
**Structure récurrente** :
```text
"Transform this photo into a hand-painted Studio Ghibli style illustration.
CRITICAL: This is an EDIT of the photo, NOT a creation.
Apply:
1) Hand-painted texture: visible gouache/watercolor brushstrokes, slightly uneven color fields...
2) Natural warm colors: nuanced [X] for [Y], desaturated [Z] for [W]...
3) Detailed landscape: textured [elements], atmospheric depth...
4) Soft outlines: forms defined by color, shadows, fine lines...
5) Persons: natural proportions, simple faces (small eyes, subtle nose/mouth), painted hair...
6) Lighting: soft, warm, golden...
Maintain [specific elements] 100% accuracy.
AVOID: photorealism, 3D, thick black contours, big anime eyes..."
```

**Variantes ciblées** :
- Pour les barbes : `"ADD short uniform continuous beards to BOTH persons"`.
- Pour les couleurs : `"ADJUST colors to warmer tones: golden rocks, warm browns..."`.
- Pour les visages : `"REFINE facial features to appear younger while keeping beard length"`.

## **💡 Points clés à retenir**
1. **Édition > Création** : Toujours partir de la photo originale pour garantir la fidélité.
2. **Prompts détaillés** : Décrire *précisément* le style Ghibli (textures, couleurs, contours) + les exceptions (ex: "visages 100% fidèles").
3. **Itérations courtes** : Corriger un seul élément à la fois (barbes, couleurs, traits) pour éviter les erreurs cumulatives.
4. **Uniformité** : Utiliser des références visuelles (ex: "comme sur l’image `gen-image://0af63a0c`") pour aligner les détails (barbes, tons).
5. **Feedback utilisateur** : Intégrer systématiquement les retours pour affiner (ex: "rajeunir", "barbes plus courtes").

Complément pour améliorer le pixel-perfect:
### **🎯 Améliorer l’effet *pixel-perfect* : Stratégies concrètes**

Pour atteindre une **fidélité absolue** (100% pixel-perfect) entre vos photos originales et les versions Ghibli, voici les **méthodes avancées** à appliquer, classées par priorité :

---

---

## **🔍 1. Précision extrême des prompts**
**Problème actuel** : Les prompts génériques laissent une marge d’interprétation à l’IA.
**Solution** : **Décrire chaque élément comme un brief technique**.

### **Exemple de prompt ultra-précis** :
```text
"EDIT this photo to Studio Ghibli style with 100% PIXEL-PERFECT ACCURACY for ALL elements.
- LANDSCAPE: Keep EXACT rock shapes (positions: 3 large boulders at 40% height, left side), mountain ridges (jagged peak at 70% height, center), river path (S-curve from bottom-left to center).
- COLORS: Use hex #8A7B6D for the main rock, #A4C2A5 for mid-ground grass, #D4E6F1 for sky (15% desaturated).
- PERSON 1 (left): Hat color #C19A6B, sunglasses lens reflection angle 30°, beard shape: rectangular (width=60% of face, height=20% of chin), MUSTACHE: thin line (2px height).
- PERSON 2 (right): T-shirt logo 'P' at 10% opacity, beard: triangular (width=50% of face).
- TEXTURES: Gouache brushstrokes (size: 3-5px), NO smoothing, NO anti-aliasing on edges.
- LIGHTING: Shadow under left person’s hat (angle: 45°, opacity: 25%).
AVOID: ANY deviation from original element positions, sizes, or shapes."
```

**→ Pourquoi ça marche** :
- **Coordonnées spatiales** (`40% height`, `left side`) : Ancre les éléments dans l’espace.
- **Valeurs hexadécimales** : Garantit les couleurs exactes.
- **Formes géométriques** (`rectangular`, `triangular`) : Évite les interprétations artistiques.
- **Taille en pixels** (`2px height`) : Précision absolue pour les petits détails.

---

---

## **🎨 2. Méthode des "calques de correction"**
**Processus en 3 étapes** pour éviter les erreurs cumulatives :

### **Étape 1 : Isolation des éléments**
- **Générer une version par couche** :
  1. **Paysage seul** (montagnes, arbres, rochers) → Valider la fidélité.
  2. **Personnages seuls** (visages, vêtements, accessoires) → Valider la fidélité.
  3. **Combinaison finale** : Superposer les couches validées.

**Exemple** :
```text
# Étape 1 : Paysage
"Transform ONLY the landscape (mountains, trees, rocks, sky) to Ghibli style. KEEP ALL SHAPES, POSITIONS, AND COLORS 100% IDENTICAL to original. Persons must remain UNCHANGED (blurred or masked)."

# Étape 2 : Personnages
"Transform ONLY the persons to Ghibli style. KEEP FACES 100% IDENTICAL (pixel-perfect). Landscape must remain UNCHANGED."

# Étape 3 : Fusion
"Combine the validated landscape and persons layers. NO additional changes."
```

**→ Avantages** :
- **Contrôle granulaire** : Chaque élément est validé séparément.
- **Moins d’artefacts** : Évite les distorsions liées aux corrections multiples sur une seule image.

---

## **📐 3. Utilisation de références visuelles internes**
**Problème** : L’IA "oublie" les détails entre les itérations.
**Solution** : **Réutiliser les images validées comme références**.

### **Technique** :
- **Dans le prompt** :
  ```text
  "Use the validated landscape from gen-image://809eec4d as EXACT reference for:
  - Rock shapes and positions.
  - Mountain textures and colors.
  Apply Ghibli style to the NEW photo, but MATCH these elements pixel-perfectly."
  ```
- **Pour les personnages** :
  ```text
  "Use the person from gen-image://0af63a0c (with correct beard shape and eye color) as EXACT reference.
  Apply the same beard style, eye color (#4A90E2), and facial proportions to the NEW person."
  ```

**→ Résultat** :
- **Cohérence absolue** entre les images.
- **Gain de temps** : Pas besoin de redécrire les détails déjà validés.

## **🔬 4. Outils de validation pixel-perfect**
**Pour vérifier objectivement la fidélité** :
1. **Superposition des images** :
   - Ouvrir la photo originale et la version Ghibli dans un logiciel (ex: Photoshop, GIMP).
   - **Mode "Différence"** : Les zones non identiques apparaissent en noir/rouge.
   - **Seuillage** : Isoler les différences > 2-3 pixels.

2. **Outils en ligne** :
   - [Pixel Diff](https://pixeldiff.com/) : Compare deux images et affiche les différences.
   - **Tolérance** : Régler à 1-2% pour détecter les écarts mineurs.

3. **Vérification manuelle** :
   - **Grille** : Diviser l’image en carrés de 10x10 pixels et vérifier chaque section.
   - **Zoomer à 400%** : Vérifier les contours (yeux, barbes, accessoires).
